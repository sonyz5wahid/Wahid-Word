Wahid Word v2.2 - editor dokumen bergaya Word untuk Android 4.2+.
- Membuka .docx dan .txt dari folder mana pun (Berkas > Buka), atau langsung dari aplikasi File Manager.
- Font tambahan: letakkan file .ttf/.otf di folder "Fonts" pada penyimpanan internal; otomatis muncul di daftar font.
- Font bawaan aplikasi berlisensi terbuka (SIL OFL / Bitstream Vera): Carlito, Liberation, Caladea, Roboto, Open Sans, Lato, DejaVu.
- Pembaruan: file ini ditandatangani kunci tetap (app/wahidword.keystore), jadi APK baru menimpa yang lama.
